# src/interiors/ —— 室内细节

每个房间一个文件，导出 `createXxxInterior(room)`，返回一个 `THREE.Group`。
建筑模块把它挂在房间的**室内原点**上：

- 原点在该房间室内地坪的西北角（墙内侧），`y = 0` 是室内地坪面；
- 坐标方向与全局一致：+X 东、-Z 北、+Y 上，1 单位 = 1 米；
- 室内净尺寸由 `src/layout.js` 推出（墙厚 0.24 m），不要在这里写死。
